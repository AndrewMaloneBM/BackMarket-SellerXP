# Rules for every step

Read this before every step.

1. Do only the step you were given. Do not start the next one.
2. Do not redesign. Match the picture and the values named in the step.
3. Use Back Market's Revolve components from Front Apps where one exists. `LOOK.md` lists them.
4. Shared hub code lives in `/hub`. Team content lives in `/teams/<team>`. Never copy hub code into a team folder.
5. Text in [square brackets] is an undecided placeholder. Keep it exactly as written. Never invent a value.
6. Do not use dot or bullet characters as separators in the interface.
7. Use the words in the table below. Never show code names to users.
8. Everything must work by keyboard, with a visible focus ring: `2px solid hsl(225,100%,60%)`, offset 2px.
9. Files in `source/` are mock-ups. Copy their sizes, spacing, colours and wording. Do not copy their structure. Never use the tags `x-dc`, `sc-if`, `sc-for`, `dc-import` or the `{{...}}` syntax.
10. If you cannot open pictures, use the matching file in `source/` instead. It has the same name.
11. If a picture shows something the step does not mention, leave it out and say so in your report.
12. If a step is unclear, or seems to need a change outside the step, stop and ask.
13. Do not add a new dependency without asking.
14. When done, go through the step's checklist and report pass or fail for each line. Then stop.
