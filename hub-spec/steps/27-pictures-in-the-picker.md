# Step 27: Pictures in the picker

## Goal
Each card in the version picker shows a small picture of that version.

## Do
1. Before writing anything, tell Andrew how you plan to take the pictures and whether it needs a new dependency. Wait for a yes.
2. At publish time, take a small picture of the first screen of each version, and of "Before" when it exists.
3. Save them with the prototype.
4. Show each one in its card's picture area, scaled to fit, keeping its shape.
5. If a picture is missing or fails, keep the plain neutral block. Never block publishing because of a picture.

## Leave out
Pictures for every screen. Only the first screen of each version.

## Checklist
- Andrew agreed to the approach before any code was written.
- Each version card shows its own picture.
- "Before" shows the current design.
- A missing picture falls back to the neutral block.
- Publishing still works when a picture fails.
