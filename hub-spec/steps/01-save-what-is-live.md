# Step 01: Save what is live

## Goal
The repo matches the live SellerXP site, in a private place.

## Do
1. Tell Andrew which remote this repo pushes to, and whether it is public or private.
2. If it is public, stop. Tell Andrew how to move it to a private Back Market repo. Do nothing else.
3. If it is private, commit the current state exactly as it is. Do not move, rename or tidy anything.
4. Push.

## Leave out
Any restructuring or clean-up.

## Checklist
- The remote is private.
- `git status` is clean.
- One new commit holds the current live state.
- No file was moved or renamed.
