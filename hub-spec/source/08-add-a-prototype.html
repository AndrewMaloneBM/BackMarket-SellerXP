Add a prototype

You build and publish from OpenCode. Two commands take you from an idea to a card on the hub.

Every time

  1. 1
    Start Open OpenCode in the prototypes folder and run this. It asks a few questions about your idea, creates the page from the Back Office shell, then opens a preview.
    /new-prototype
  2. 2
    Build Describe what you want in plain words. The preview updates as OpenCode works. Nothing is public yet.
  3. 3
    Publish Run this when it's worth showing. It checks your card is complete, and your prototype is on the hub a couple of minutes later. Run it again any time to update.
    /publish

First time? Set up once

  1. 1
    Get access Ask in [#channel] to join the prototype builders GitHub team.
  2. 2
    Install OpenCode Follow the install guide. It takes you from nothing to a working terminal.
  3. 3
    Run setup Paste this in your terminal. It installs everything and publishes a test page, so you know it works.
    npm run setup

What you're asked at the start

Your answers become your card. Your name, the dates and the link are filled in for you. Status starts at Exploring, and you can change it when you publish.

Name
Up to 40 characters. A name, not an objective.
Pages
Every Back Office page it touches, or Cross-page. Picked from a list.
People
Who is working on it with you. Picked from a list.
Problem
One sentence on what's broken for sellers today.
Goal
One line with a metric, from today's number to the target.
Links
Your brief or PRD, and any research findings. Optional.
